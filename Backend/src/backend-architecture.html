RAG-PRA 后端架构图

业务逻辑层 (src/) 与 HTTP 适配层 (routers/) 调用关系

HTTP 适配层 / routers/

  • 请求校验 (Pydantic 模型约束)
  • 文件安全 (路径遍历防护)
  • 并发控制 (asyncio.Lock 写锁)
  • 原子删除 (临时目录 + 回滚)
  • SSE 流式适配 + 错误翻译
  • 响应格式化 + 耗时计算

业务逻辑层 / src/

  • pipeline.py 串联全流程
  • questions_processing.py 问答引擎
  • retrieval.py 混合检索
  • reranking.py LLM 重排序
  • ingestion.py 索引构建
  • metadata.py 元信息管理

依赖注入 / dependencies.py

  • Pipeline 单例 (双重检查锁)
  • asyncio.Lock 写锁共享
  • MetadataManager 单例
  • apply_config_to_pipeline() 热更新
  • get_logger() 统一日志
  • 解耦 routers 与业务模块
