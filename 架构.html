RAG架构图

用户输入 → HTTP POST → FastAPI → Pipeline → 5步RAG → SSE流式回传 → React渲染

前端请求流 (React SPA)

  • • User Input 用户输入 → handleAnswer() 处理函数 → POST /api/answer/stream
  • • SSE Reader 读取器: getReader() → decode → parse data: lines
  • • 3类事件: step(步骤进度) | token(流式令牌) | result(结果)
  • • React State: setSteps 步骤更新 → setStreamingText 流式文本 → setAnswer 设置答案

5步 RAG 流水线 (Pipeline)

  • • Step1 检索: Router 路由→FAISS 向量检索/BM25 关键词检索→Hybrid Fusion 混合融合→Page Restore 页面还原
  • • Step2 重排: ThreadPoolExecutor 并发 LLM Reranker + Score Fusion 分数融合
  • • Step3 上下文: n-gram Keyword Extract + Snippet Cut 切片 window=100 + Prompt Build 拼接
  • • Step4 生成: qwen3.6-plus stream=True 逐 token, json_repair 兜底
  • • Step5 校验: 过滤 LLM 幻觉页码, yield result 事件

SSE 回传与闭环 (Event Stream)

  • • 右侧 SSE 通道: 5个事件触发点 (Step1-Step5) 沿虚线向上推送
  • • 前端实时消费: 步骤进度条 + 逐字流式渲染 typewriter 效果
  • • 完成后: saveHistory() 历史保存 → POST /api/history → history.db
  • • trace_id 追踪标识: 前端生成 → HTTP header → 全链路日志
